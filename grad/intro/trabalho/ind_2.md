# Trabalho — Introdução à Programação em C

**Valor total: 1,5 ponto** - Cada questão vale **0,3 ponto**.

## Questão 1 — Solução de problemas e pensamento computacional

- Valor: 0,3 ponto

Uma empresa deseja criar um programa simples para calcular o valor final de uma compra. O programa deve receber o valor do produto e a quantidade comprada. Depois, deve calcular e exibir o valor total.

Antes de escrever o código, descreva os três elementos principais do problema:

a) Quais são as **entradas**?
b) Qual é o **processamento**?
c) Qual é a **saída** esperada?

## Questão 2 — Tipos de dados, operadores e tabela verdade

- Valor: 0,3 ponto

Considere o seguinte trecho de código em C:

```c
int idade = 20;
float media = 7.5;
int faltas = 12;
```

Analise a expressão lógica abaixo:

```c
idade >= 18 && media >= 6.0 && faltas <= 10
```

Responda:

a) Qual será o resultado da expressão: verdadeiro ou falso?
b) Explique brevemente o motivo.

## Questão 3 — Comandos de entrada e saída

- Valor: 0,3 ponto

Escreva um programa em C que leia o nome de um funcionário, o salário atual e exiba uma mensagem com esses dados. Exemplo de saída esperada:

```text
Funcionario: Ana
Salario atual: R$ 2500.00
```

## Questão 4 — Estruturas de decisão

- Valor: 0,3 ponto

Uma empresa classifica candidatos para uma vaga de estágio de acordo com a nota obtida em uma prova técnica. A regra é:

```text
Nota maior ou igual a 7: Aprovado para entrevista
Nota menor que 7: Não aprovado
```

Escreva um programa em C que leia a nota do candidato e informe a situação.

## Questão 5 — Estruturas de repetição, vetores e matrizes

- Valor: 0,3 ponto

Uma equipe de estágio precisa registrar as notas de 5 candidatos em uma prova técnica. Escreva um programa em C que:

a) leia as 5 notas usando um vetor;
b) calcule a média das notas usando uma estrutura de repetição;
c) exiba a média final.
