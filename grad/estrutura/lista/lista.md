# Lista de Exercícios — Estrutura de Dados

## Tema 1 — Estruturas de Dados: Conceitos e Representação

1. Explique, com suas palavras, o que é uma estrutura de dados e por que ela é importante na construção de algoritmos.

2. Diferencie dado, informação, variável, tipo de dado e estrutura de dados.

3. Cite três exemplos de estruturas de dados lineares e três exemplos de estruturas de dados não lineares.

4. Explique a diferença entre uma estrutura de dados estática e uma estrutura de dados dinâmica.

5. Compare o uso de vetor e lista encadeada em relação à inserção, remoção e acesso aos elementos.

6. Considere um vetor com 10 posições. Explique o que acontece quando tentamos acessar uma posição fora dos limites do vetor.

7. Crie uma representação em C para armazenar os dados de um aluno: matrícula, nome, idade e média final.

8. Crie um vetor de structs para armazenar os dados de 5 produtos, contendo código, nome e preço.

9. Explique o papel dos ponteiros na criação de estruturas de dados dinâmicas.

10. Diferencie alocação estática e alocação dinâmica de memória.

11. Escreva um programa que leia 5 números inteiros em um vetor e exiba os valores na ordem inversa.

12. Crie um programa que armazene os dados de 3 livros usando struct e depois exiba todos os livros cadastrados.

---

## Tema 2 — Listas e Ordenação

1. Explique o que é uma lista linear e dê um exemplo de aplicação real.

2. Diferencie lista sequencial e lista encadeada.

3. Implemente uma lista sequencial usando vetor, com as operações de inserir, remover e listar elementos.

4. Crie uma função que busque um elemento em uma lista sequencial e retorne sua posição.

5. Implemente uma lista encadeada simples com inserção no início.

6. Implemente uma lista encadeada simples com inserção no final.

7. Crie uma função para remover um elemento específico de uma lista encadeada simples.

8. Crie uma função para contar quantos nós existem em uma lista encadeada.

9. Implemente uma função que imprima todos os elementos de uma lista encadeada.

10. Explique a diferença entre lista simplesmente encadeada, lista duplamente encadeada e lista circular.

11. Implemente uma lista duplamente encadeada com inserção no início e no final.

12. Crie uma função para encontrar o maior valor armazenado em uma lista encadeada.

13. Explique o funcionamento do algoritmo Bubble Sort.

14. Implemente o Bubble Sort para ordenar um vetor de números inteiros.

15. Explique o funcionamento do Selection Sort.

16. Implemente o Selection Sort para ordenar um vetor de números inteiros.

17. Explique o funcionamento do Insertion Sort.

18. Implemente o Insertion Sort para ordenar um vetor de números inteiros.

19. Compare Bubble Sort, Selection Sort e Insertion Sort em relação à quantidade de trocas e comparações.

20. Dado um vetor desordenado com 10 números, aplique manualmente duas passagens do Bubble Sort e mostre o resultado parcial.

21. Crie um programa que leia 10 números, armazene em um vetor, ordene em ordem crescente e exiba o resultado.

22. Crie um programa que ordene uma lista de produtos pelo preço usando uma struct.

## Tema 3 — Pilhas e Filas

1. Explique o conceito de pilha e o princípio LIFO.

2. Dê três exemplos reais de uso de pilha no cotidiano ou na computação.

3. Implemente uma pilha usando vetor, com as operações push, pop e listar.

4. Crie uma função para verificar se uma pilha está vazia.

5. Crie uma função para verificar se uma pilha está cheia.

6. Implemente uma pilha usando lista encadeada.

7. Crie um programa que use pilha para inverter uma palavra digitada pelo usuário.

8. Explique o conceito de fila e o princípio FIFO.

9. Dê três exemplos reais de uso de fila no cotidiano ou na computação.

10. Implemente uma fila usando vetor, com as operações inserir, remover e listar.

11. Implemente uma fila circular usando vetor.

12. Implemente uma fila usando lista encadeada.

13. Crie um programa que simule uma fila de atendimento bancário, permitindo adicionar clientes e atender o próximo cliente.

14. Compare pilha e fila, explicando quando cada uma deve ser utilizada.

## Tema 4 — Algoritmos Avançados

1. Explique o que é uma árvore e diferencie raiz, nó, folha, grau e altura.

2. Implemente uma árvore binária de busca com as operações de inserir, buscar e imprimir em ordem crescente.

3. Explique por que a impressão em ordem de uma árvore binária de busca exibe os valores em ordem crescente.

4. Crie uma função para contar a quantidade de nós de uma árvore binária.

5. Crie uma função para encontrar o menor e o maior valor em uma árvore binária de busca.

6. Explique o que é uma árvore AVL e qual problema ela tenta resolver.

7. Mostre, com desenho ou explicação, um caso em que uma rotação simples à direita é necessária em uma árvore AVL.

8. Mostre, com desenho ou explicação, um caso em que uma rotação simples à esquerda é necessária em uma árvore AVL.

9. Explique o que é recursão e por que ela é muito usada em árvores.

10. Crie uma função recursiva para calcular o fatorial de um número.

11. Crie uma função recursiva para calcular a soma dos elementos de um vetor.

12. Explique o conceito de busca binária e em que condição ela pode ser usada.

13. Implemente a busca binária em um vetor ordenado.

14. Compare busca linear e busca binária em relação ao desempenho.

15. Explique o que é complexidade de algoritmo usando a notação O.

16. Determine a complexidade aproximada dos seguintes casos: acesso direto em vetor, busca linear, busca binária e Bubble Sort.

17. Explique o funcionamento básico do Quick Sort.

18. Explique o funcionamento básico do Merge Sort.

19. Compare Quick Sort e Merge Sort com Bubble Sort em relação ao desempenho.

20. Crie um programa que permita cadastrar números em uma árvore binária de busca e depois exibir os valores em ordem crescente.
